# CHANGELOG — TechBairro

Este arquivo registra as alterações realizadas no projeto TechBairro.

## [3.3.1] - 2026-10-29
### Adicionado
- Organização do projeto em camadas.
- Criação dos módulos banco.py, cliente.py e validacao.py.
- Criação do arquivo testar_validacao.py para testar as validações.

### Corrigido
- Correção de problemas identificados durante os testes.
- Verificação das validações dos dados dos clientes.

## [3.3.0] - 2026-10-21
### Corrigido
- Correção dos problemas ao alterar e excluir clientes.
- Verificação da existência do registro antes de confirmar uma alteração.
- Ajustes nas mensagens de sucesso e confirmação.

## [3.2.1]

- Pesquisa de clientes pelo nome.

## [3.0.0]
